# Anime Info

Get detailed information about a specific anime including relations and recommendations.

## Endpoint

```
GET /api/anime/:id
```

## Path Parameters

| Parameter | Type   | Required | Description         | Example  |
|-----------|--------|----------|---------------------|----------|
| `id`      | string | Yes      | Anime session/token | `abc123` |

# Anime Releases

Get the complete episode list for a specific anime with pagination and sorting.

## Endpoint

```
GET /api/anime/:id/releases
```

## Path Parameters

| Parameter | Type   | Required | Description         | Example  |
|-----------|--------|----------|---------------------|----------|
| `id`      | string | Yes      | Anime session/token | `abc123` |

## Query Parameters

| Parameter | Type   | Required | Description                    | Example              |
|-----------|--------|----------|--------------------------------|----------------------|
| `sort`    | string | No       | Sort order (`desc` or `asc`)   | `?sort=episode_desc` |
| `page`    | number | No       | Page number (default: 1)       | `?page=2`            |

## Examples

**Get episode list (descending):**

```bash
curl "http://localhost:7860/api/anime/abc123/releases?sort=episode_desc"
```

**Paginate episodes:**

```bash
curl "http://localhost:7860/api/anime/abc123/releases?page=2"
```

## Cache Duration

24 hours (86400 seconds)
